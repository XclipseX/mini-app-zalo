# Zalo Mini App

**Tóm tắt:** Ứng dụng chạy bên trong Zalo, không cần tải app riêng; viết bằng React + zmp-sdk + zmp-ui.

## Nội dung chính
- Đi kèm Zalo OA của doanh nghiệp.
- Phát triển bằng zmp-cli / Zalo Mini App Extension; test qua 3 môi trường Development → Testing → Production.
- Template F&B gần nhất: ZaUI Coffee (github.com/Zalo-MiniApp/zaui-coffee).
