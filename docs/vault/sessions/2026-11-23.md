## Phiên Checkout SDK + isStaff (23/11)
- Server `functions/src/checkout.ts`: `buildCheckout()` tạo tham số `Payment.createOrder` (amount, desc, item, extradata `{orderId,storeId}`, method `{id: COD|BANK[_SANDBOX]}`) + `mac` = HMAC-SHA256(CHECKOUT_PRIVATE_KEY, các trường sort abc `k=v&...`, object → JSON). `verifyCallback()` kiểm tra mac của Notify (`appId&orderId&method`) và Callback trạng thái (`appId&amount&description&orderId&message&resultCode&transId`).
- `createOrder` nhận `method` ("COD"/"BANK"), lưu `paymentMethod`, `paymentStatus: "unpaid"`, trả `{orderId,total,checkout}`.
- Endpoint mới: `checkoutCallback` (trả `{returnCode, returnMessage}`, cập nhật `zaloOrderId`, `paymentStatus` paid/failed, `transId`), `isStaff`.
- Secret mới `CHECKOUT_PRIVATE_KEY`; env `CHECKOUT_SANDBOX` (mặc định sandbox, đặt "false" khi lên thật).
- Client: `payCheckout()` trong `zalo.ts` (MOCK bỏ qua); giỏ hàng chọn "Trả tại quầy" / "Chuyển khoản"; Rewards chỉ hiện link nhân viên khi `isStaff()` (MOCK luôn true).
